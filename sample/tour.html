幻灯片

THE DIFFERENCE

同样是演示，差别在这里

普通 PPT

  • 版式固定，换个屏幕就变形
  • 动画要一页页手动设置
  • 数据变化只能重新截图
  • 放大会糊，矢量图形失真

HTML 演示（本软件）

  • 矢量渲染，任意分辨率都清晰
  • 随滚动自动入场，无需配音效点
  • 数据可实时计算、动态生长
  • 能响应鼠标、点击与键盘
把鼠标移到页面任意位置——背景的光会跟着你。
GETTING STARTED

三种方式，立刻开始

打开 HTML

拖入或选择已有的 AI 生成 HTML，自动识别每一页，立刻播放。

用 AI 生成

描述需求、上传数据或图片，AI 直接产出带动效的幻灯片。

粘贴 HTML

任何地方复制来的 HTML 代码，粘贴即可打开，无需存成文件。

EDIT

点谁改谁，像设计工具一样

单击任意元素选中，拖动移动、八向手柄缩放；双击直接改文字。改动实时写回 HTML。

移动与缩放

拖动元素即移动，八个手柄自由缩放，角手柄等比、边手柄单轴。

样式与层级

加粗、斜体、字号、文字色、背景色、上移一层下移一层，一键完成。

快捷键

Ctrl+D 复制元素 · Ctrl+Z 撤销 · 方向键微调 1px

切到「编辑」模式，动效会自动暂停，所有元素都能选中。
PRESENT

演讲者模式，从容不迫

投影窗口放正片，你的窗口显示当前页、下一页预览、演讲者备注、计时器和全部缩略图；两边翻页实时同步。

下一页预览

提前知道接下来讲什么，衔接自然。

演讲者备注

每页的 data-notes 只在你的窗口显示。

计时器

自动计时，掌握节奏，不超时。

ANNOTATE

边讲边画，讲到哪标到哪

画笔、荧光笔、激光笔、橡皮擦一应俱全；笔迹以归一化坐标保存，投影与控制台自动对齐。

落笔光点

画笔与橡皮显示落笔位置光点，激光笔带荧光轨迹。

同步显示

在控制台画，投影上同步出现。

撤销与清空

画错了随时撤销，或一键清空本页。

QUICK START

现在就可以开始

三种开始方式

① 拖入 .html 文件；② 点「用 AI 生成」描述需求；③ 直接粘贴 HTML 代码。

播放 / 编辑一键切换

顶部中间的开关。编辑模式下：单击选中元素、拖动移动、Shift 点选多个、双击改文字。

右侧属性面板

按元素类型给出不同选项：文本有字体行高、图片有滤镜、形状有渐变与内边距。

标注与演讲

底部可选画笔 / 荧光笔 / 激光笔；点「演讲者模式」把正片投到副屏，本机看备注与下一页。

常用快捷键

← → 翻页 · B/W 黑屏/白屏 · Ctrl+Z 撤销 · Ctrl+S 保存

AI 与设置

设置里填一次 API Key 即可多模型切换；还能编辑 AI 的提示词，让它按你的规范写 HTML。

READY

内容才是主角，
HTML 让它活起来。

Lumina 不引入任何框架，不替你决定风格——它把你手里的 HTML 变成一场可以讲、可以动、可以互动的演示。

如需编辑，切到「编辑」模式；动效会自动暂停，方便你修改任意元素。
